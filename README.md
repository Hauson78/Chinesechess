# Chinesechess · 老人友好中国象棋

一个纯前端、单文件的中国象棋对弈网页应用，专为手机竖屏优化，老人友好向。

在线试玩：见部署说明（可直接把 `index.html` 发到任意静态托管，或本地双击打开）。

## 特性

- **完整规则引擎**：将 / 仕 / 相（塞象眼）/ 马（蹩马腿）/ 车 / 炮（炮架）/ 兵（过河横走），九宫、将帅对脸、将死、困毙、120 回合无吃子和棋。
- **本地 AI 三档**：简单 / 中等 / 困难，纯浏览器内运算，无需联网、无后端。
  - 算法栈：α-β 剪枝 + 迭代加深 + 静态搜索（quiesce）+ 空着裁剪 + 杀手走法 + 历史表 + Zobrist 置换表 + 位置表 PST + 将军延伸 + 被攻击惩罚。
  - 困难档约 2 秒出一步，手机端秒应。
- **开局库**：18 个常见开局变例（中炮、飞相、仙人指路、过宫炮、起马、对兵等）。
- **残局挑战**：双车错、马后炮、海底捞月、单马擒士、兵临城下 5 个经典残局。
- **老人友好 UI**：
  - 大棋子、高对比木质棋盘、点选走子、金圈标记可行走点。
  - 随机执红 / 执黑，执黑时电脑自动先行。
  - 悔棋、提示、重开、Web Audio 音效、localStorage 存战绩与设置。
  - 棋盘自动撑满手机屏幕，顶部标题最小化。

## 玩法

1. 点选自己的棋子 → 金圈 / 金环标出可走点。
2. 再点目标点即走子；点错可随时「悔棋」，不会下可点「提示」。
3. 开局前在主菜单选电脑水平（简单 / 中等 / 困难）。

## 本地运行

直接双击 `index.html` 即可在浏览器打开，或：

```bash
# 任意静态服务器
npx serve .
# 或
python -m http.server 8000
```

手机访问：电脑与手机同一 WiFi，用 `http://<电脑IP>:8000/` 打开即可。

## 技术栈

- 原生 HTML / CSS / JavaScript，无任何依赖、无构建、无 CDN 素材。
- 单文件 `index.html`（约 1600 行），可随意 fork、改、部署到任意静态托管（GitHub Pages / Vercel / Netlify / 对象存储均可）。

## 部署到 GitHub Pages

1. 仓库 Settings → Pages → Source 选 `main` 分支 `/root`。
2. 稍等片刻，访问 `https://<用户名>.github.io/Chinesechess/`。
